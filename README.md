# Sana Photo Collection（只读公开版）

## ▶ 打开网站：https://shigurewu.github.io/sana-photo-collection/

諸橋沙夏（=LOVE）官方生写真收藏图鉴的静态公开版，部署在 GitHub Pages 上。

- `index.html` — 单文件页面（内联 CSS/JS，无构建步骤、无外部资源），打开即用
- `data.json` — 目录数据快照：369 个系列、950 张单张（由主站导出，勿手改）
- `.nojekyll` — 让 GitHub Pages 原样发布文件

## 功能

- **图鉴**：搜索（支持模糊匹配、假名互通、年月查询如「2019 9月」）+ 照片墙，点卡片看详情
- **系列**：系列搜索 + 年份 / 类别 / 状态筛选，点系列可过滤照片墙
- **时间**：按年份、月份（含「无印字年月」「年月未定」）、款式收窄照片墙

## 说明

- 本站为只读版，不含收藏 / 已拥有 / 想买等个人功能，收藏数据仍只保存在主站
- 第三方实物图（110 张）直接引用来源站（駿河屋 / Mercari）的图片显示，详情里附来源链接；还剩 9 张显示为「图片待补充」占位：5 张本身无图、3 张第三方来源只有整套合照、1 张为用户实物图（存在主站私有空间，公开版无法引用）
- 图片版权归官方及各来源所有；更新数据时重新导出 `data.json` 并提交即可
